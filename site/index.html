Helpdesk Corporativo

Sistema de chamados com três perfis (cliente, agente e administrador), chat em tempo real e indicadores de SLA e CSAT. API REST em Node.js e TypeScript, com foco em segurança, testes e execução reproduzível com Docker.

Destaques de engenharia

Autorização por perfil e por dono

Além do RBAC, cada rota verifica o dono do recurso: um cliente só lê, cancela, avalia e conversa nos próprios chamados. O remetente de uma mensagem vem do token, nunca do corpo da requisição.

Protocolo sem colisão

O protocolo HD-AAAA-NNNNN é gerado a partir do ID dentro de uma transação, eliminando a condição de corrida de um contador baseado em count().

Tempo real autenticado

Socket.io exige JWT no handshake; cada usuário entra na própria sala, e as notificações chegam só para quem deve recebê-las.

Validação e erros centralizados

Entradas validadas com Zod; erros do Prisma mapeados para 404/409; Helmet e limite de tentativas no login, com a mesma resposta para e-mail inexistente e senha errada.

Arquitetura testável

createApp(deps) recebe Prisma e Socket.io por injeção de dependência: os testes exercitam as rotas HTTP reais sem banco. Um teste garante que toda rota está nesta documentação.

Entrega

Imagens Docker multi-stage sem root, Docker Compose com healthchecks, CI no GitHub Actions (type-check, testes, build e imagens) e deploy validado em Linux na AWS EC2.
